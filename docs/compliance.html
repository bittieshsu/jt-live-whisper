資料保護與合規Data protection & compliance

資料不出去Your data stays in

語音、逐字稿、翻譯、摘要都在你自己的設備上處理，不需要任何雲端 AI 服務，讓組織比較容易符合個人資料保護、資訊安全與 AI 管理的要求。Speech, transcripts, translations and summaries are processed on your own hardware with no cloud AI service, which makes privacy, security and AI governance requirements easier to meet.

個資法、GDPR、ISO/IEC 27001、ISO/IEC 42001 檢驗的是組織怎麼管理，不是某一套軟體，所以本工具箱不宣稱「通過」或「符合」任何認證。這一頁說明工具本身做到什麼，以及你的組織使用後還要做哪些事。本頁不是法律意見。Privacy laws and ISO/IEC 27001 / 42001 assess how an organization is managed, not a piece of software, so the toolbox claims no certification. This page explains what the tool does and what your organization still needs to do. It is not legal advice.

資料在哪裡Where your data lives

錄音、逐字稿、摘要都在你的內網裡處理與保存；雲端 AI 服務完全用不到。Recordings, transcripts and summaries are processed and stored inside your network; no cloud AI service is involved.

資料Data在哪裡處理、存在哪裡Where it is processed and stored
會議錄音、即時音訊Meeting recordings, live audio你的電腦；選用 GPU 伺服器時送到你自己架設的 GPU 伺服器辨識，辨識完立刻刪除暫存音檔Your computer; with a GPU server, audio goes to your own server for recognition and the temporary file is deleted right after
逐字稿、翻譯、摘要Transcripts, translations, summaries你的電腦（logs/）；翻譯與摘要送到你自己設定的 LLM 伺服器（例如內網的 Ollama）Your computer (logs/); translation and summaries use the LLM server you configure (e.g. Ollama on your LAN)
錄音檔Audio files你的電腦（recordings/）Your computer (recordings/)
朗讀用的參考錄音（聲音）Reference recordings for text-to-speech (voices)你的電腦（tts_voices/）；用 GPU 伺服器合成時伺服器依內容快取一份，刪除聲音時兩邊一起刪（伺服器連不上時記下來，之後補刪）Your computer (tts_voices/); the GPU server caches a copy by content, and deleting a voice deletes both (if the server is unreachable, it is deleted later)
設定（含密碼雜湊、轉發平台的認證）Settings (password hashes, forwarding credentials)你的電腦（config.json）Your computer (config.json)
  • 不需要 ChatGPT、Claude、Gemini 等雲端 API 金鑰，不會把內容送給第三方 AI 服務No ChatGPT, Claude or Gemini API keys; nothing is sent to third-party AI services
  • WebUI 網頁不載入外部的字型、腳本或追蹤程式The WebUI loads no outside fonts, scripts or trackers
  • 所有 AI 模型都是開源授權，在自己的設備上執行；模型、版本與授權都列在文件裡All AI models are open-licensed and run on your hardware; models, versions and licenses are documented

工具本身做到的What the tool does

存取控制Access control

  • WebUI：管理密碼與唯讀密碼（設定檔只存雜湊）、限制哪些 IP 可以連、加密連線（TLS），反向代理後面也能正確判斷來源WebUI: admin and read-only passwords (only hashes stored), IP allow-list, TLS, correct client detection behind a reverse proxy
  • 安全設定、轉發、關鍵字通知、懸浮字幕這幾頁只有在本機才能打開Security, forwarding, keyword alert and overlay settings open only on the local machine
  • REST API：每個呼叫端一把金鑰（只存雜湊），每個呼叫端只看得到自己送的作業；從網址抓音檔時只允許設定好的主機REST API: one key per client (only hashes stored); each client sees only its own jobs; audio URLs limited to allowed hosts
  • 伺服器版的服務以安裝資料夾的擁有者身分執行，不會因為用 sudo 安裝就一律以 root 執行The server edition runs as the install folder's owner, not root just because sudo was used

可追溯、可人工覆核Traceable, reviewable

  • 會議摘要的決議、待辦、風險等每一條都附時間點與引用的原文，可以回到逐字稿查證Every decision, action item and risk in a meeting summary cites timestamps and the source text
  • 引用驗證不過的項目直接不輸出；整段摘要裡找不到依據的數字或名詞會標示出來Items whose citations do not check out are dropped; ungrounded numbers or names in the summary are flagged
  • 校正後的逐字稿保留原始辨識結果；校正幅度異常時自動保留原文Corrected transcripts keep the raw recognition; abnormal edits fall back to the original

透明與品質Transparency and quality

  • 原始碼公開（Apache-2.0），可以自行稽核Open source (Apache-2.0), auditable
  • 準確度、速度與已知限制公開在 BENCHMARKS.mdAccuracy, speed and known limits are published in BENCHMARKS.md
  • 每次發版前跑完整的守門測試；改了什麼都記在 CHANGELOGA full release gate runs before every release; every change is in the CHANGELOG
  • 模型與上游程式固定版本，不會在你不知情時換掉Models and upstream code are pinned; nothing changes behind your back

朗讀與保存期限Text-to-speech and retention

  • 內建的 8 個聲音是 AI 依文字描述產生，不是真人錄音；匯入自己的聲音要勾選「已取得錄音者的書面同意」並填寫來源The 8 built-in voices are AI-generated from text descriptions, not recordings of real people; importing your own requires confirming the speaker's written consent and recording its source
  • 錄音者要求刪除時，刪除聲音會一併刪掉 GPU 伺服器上的快取When a speaker asks for deletion, deleting the voice also deletes the GPU server's cached copy
  • REST API：確認收到（ACK）後刪除作業內容；沒有確認的保留 7 天REST API: job content is deleted after acknowledgement; unacknowledged jobs are kept 7 days
  • 日誌不記錄金鑰、授權標頭、詞彙庫與逐字稿內容Logs never contain keys, authorization headers, glossaries or transcript text

你的組織使用後要做的What your organization does

錄音前Before recording

  • 告知與同意：告知與會者用途、保存多久、誰看得到，依組織規範取得同意Notice and consent: tell participants the purpose, retention and who can see it; get consent per your policy
  • 用途限制：決定哪些會議可以錄（人事、法務、醫療要另外考慮）；只錄需要的，可以只即時轉錄、不存錄音Purpose limits: decide which meetings may be recorded; record only what you need, or transcribe live without keeping audio

部署與存取Deployment and access

  • 一定要設密碼：WebUI 開在所有網路介面上，沒設密碼又沒限制來源時，同網段的人連得進來；設管理與唯讀密碼、限制 IP，跨網段開 TLSAlways set passwords: the WebUI listens on all interfaces; set admin and read-only passwords, restrict IPs, and use TLS across networks
  • GPU 伺服器與 LLM 伺服器放在內網：用防火牆只開給需要的電腦，跨網段走 VPNKeep the GPU and LLM servers internal: firewall them to the machines that need them and use a VPN across networks
  • 主機安全：系統更新、帳號管理、磁碟加密（FileVault、BitLocker、LUKS）Host security: updates, account management, disk encryption (FileVault, BitLocker, LUKS)

保存與刪除Retention and deletion

  • 訂出保存期限：依規範定期清理 recordings/、logs/（包含備份）Set retention: clean up recordings/ and logs/ on schedule, backups included
  • 刪除要求：錄音、逐字稿、摘要、聲音、備份都要處理Erasure requests: cover recordings, transcripts, summaries, voices and backups
  • 備份：需要保存的自行備份，定期測試還原Backups: back up what you keep and test restores

人工覆核與外部服務Human review and outside services

  • AI 輸出要人確認：可能聽錯、誤譯、漏掉或寫錯決議與待辦對象；用在對外、決策、法律、醫療、財務前請對照原文Review AI output: it can mishear, mistranslate or get decisions and owners wrong; check against the source before external, legal, medical or financial use
  • 合成語音：對外使用時標示為 AI 合成；同意書寫清楚用途、範圍、期限、撤回與刪除；不可冒充本人Synthetic speech: label it as AI-generated; consent should cover purpose, scope, duration, withdrawal and deletion; never impersonate
  • 字幕轉發、外部 LLM 或 GPU 伺服器：開啟前評估那個服務的資料保存與使用政策Forwarding, outside LLM or GPU servers: assess their data retention and use policies first
